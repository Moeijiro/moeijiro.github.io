Armour

Eight sets, seven pieces each

Every set covers eight slots with seven models — helm, cuirass, mantle, girdle, signet, greaves, sabatons — and the cuirass alone rides five separate mounts so the pauldrons turn with the arms instead of floating off the shoulders.

The rules

What holds eight sets together

A set is not a look, it is a contract with the body underneath it. These four are what let a Common bandana and a Legendary broken-plate helm sit on the same character without either one cutting the jaw.

FitMeasured, not eyeballedClearance is raycast against the real reference mesh, per limb. A ray that misses returns a floor value — too low a floor drops the piece inside whatever is below it.
FaceThe helm owns the headOne model covers head and face. An open face is allowed but has to be a decision: a band of light, a nemes frame, or glazed ports — never an oversight.
MaterialOne object per materialThe importer makes one mesh part per object, not per material. A six-material mesh exported whole arrives grey and the entire palette is silently lost.
TiersRarity carries no statsMoving a set between tiers means editing the rarity and remapping its health band together, or an Uncommon set quietly outclasses every Legendary.
