What every icon obeys

Four rules do all the work in the game set. They are what keeps the eighty-fifth icon sitting next to the first one without a seam. The interface set runs on its own four: a 24-unit grid, a 1.9 stroke, round joins everywhere, and one hue per category.

Tilt−6°, alwaysShape, tone bands, engraving and spark all sit in one rotated group, so nothing can drift out of alignment between icons.
Contour#050434, stroked underThe outline sits beneath the fill, so exactly 14 units show outside the silhouette on every icon regardless of shape.
ToneThree hard bandsShade left, light band through the centre, base right. Bands are hard-edged; the gradient lives inside each band, never across them.
LightUpper left, no exceptionsThe same white four-point spark in the same place on all 85 icons — the cheapest way to make a set feel authored.
