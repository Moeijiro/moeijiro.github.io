Approach

Same three rules, whatever the medium

An icon, a particle burst, a mesh and a module all fail the same way — they look fine in isolation and fall apart in a live game.

01Read it at the real sizeNothing is judged zoomed in. An icon is checked at 20 px, an effect at arm’s length on a phone, a mesh from across the map. If it only works in the viewport, it does not work.
02Budget before beautyTri counts, draw calls, particle counts and file sizes are decided first and treated as walls, not suggestions. Pretty and unshippable is just unshippable.
03Leave it maintainableConsistent naming, one source per asset, no magic numbers buried in a script. The next person to open the file should not have to reverse-engineer it.
